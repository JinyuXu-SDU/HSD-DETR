# HSD-DETR Documentation

Documentation for the HSD-DETR project — a Hybrid Scale-Dynamic Detection Transformer for remote sensing small object detection.

Built with MkDocs. Deployed at [https://jinyuxu-sdu.github.io/HSD-DETR](https://jinyuxu-sdu.github.io/HSD-DETR).

## Building Locally

```bash
pip install -r requirements-docs.txt
mkdocs serve
```
